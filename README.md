### USOS Web Plus

</div>

**USOS Web Plus** is a userscript designed to add a simple dark mode filter and some UI improvements for the USOS web system, which is widely used by most Polish universities.

![Screenshot](https://i.imgur.com/LkWIUiY.png)

## Features

- Inverts page colors with hue rotation for a basic dark mode effect.
- Styles specific USOS UI elements for better readability in dark mode.
- Applies consistent color and styling to table headers, dialogs, frames, and info boxes.
- Cache mechanism for optimized DOM queries.
- Toggle dark mode on/off via a menu command.

## Planned Features

- More advanced theming and customization options.
- Additional UI tweaks and enhancements.
- Better handling of dynamically loaded content.
- Calculation of arithmetic and ECTS-weighted averages.

## Known Issues

- Some flags/icons may not display correctly due to Shadow DOM restrictions and styling limitations.
- Dark mode may invert images or media elements undesirably in some cases.

## Installation

Install this userscript with a compatible userscript manager such as Tampermonkey or Greasemonkey. It works on domains related to the USOS web system (`usosweb.*`, `web.usos.*`, `cas.usos.*`).
